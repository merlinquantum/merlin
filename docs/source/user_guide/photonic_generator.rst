==================
Photonic Generator
==================

Overview
--------
The photonic generator is a quantum generative model based on photonic quantum circuits. This generator can be used in photonic quantum generative adversarial network (QGAN) architectures such as the one in the reproduced papers library [1]. In a nutshell, samples from a latent distribution are encoded into a parametrized quantum circuit which outputs a different distribution depending on these samples. There can be several circuits, and their outputs are recombined using an output map to form the data which we aim to generate. Typically for image data, the images are generated in patches, and a natural choice can be that each patch is generated by a different circuit. The circuit parameters are trained, for instance in a QGAN architecture, with the aim that generated images are similar to a target dataset. 


Core building blocks
--------------------

- :class:`~merlin.models.photonic_generator.PhotonicGenerator`
  Generative model composed from one or more QuantumLayer heads.

- :class:`~merlin.models.photonic_generator.ImageAdapter`
  Adapts tensor measurements to image tensors which can easily be used in GAN architectures.

- :class:`~merlin.models.photonic_generator.LatentDistribution`
  Provides latent distribution from which samples are used to bring noise into the generator, so it can generate different data samples.


User recommendations and limitations
------------------------------------

- When choosing the size of the circuits in the quantum layers that form the photonic generator, follow the same guidelines as for other MerLin circuits. Further information on limitations on number of photons and modes can be found `here <https://merlinquantum.ai/performance/index.html#pushing-the-h100-to-its-limits>`_.  
- As a rule of thumb, when choosing the number of generator heads for patch generaton through parameter 'count', we recommend that the total number of pixels of the image (or size of the data) should be lower or equal to the number of generator heads times the output space size of each quantum circuit.
- For images, we also recommend making sure that the patches are at least of size 2x2 pixels.
